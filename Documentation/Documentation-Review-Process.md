# Documentation Review Process

Whenever an SOP or runbook is changed, the update should go through a review process before being merged.

## Review Workflow

Engineer updates document
          ↓
Peer review
          ↓
Approval
          ↓
Merge
          ↓
Updated documentation

## Example

EC2-SOP.md
   ↓
Engineer A updates
   ↓
Engineer B reviews
   ↓
Git commit
   ↓
Pull Request
   ↓
Review and approval
   ↓
Merge
   ↓
Updated EC2-SOP.md

The engineer modifies the required SOP or runbook.
